The Limit of a Function

Why We Need Limits

  • Some functions are undefined exactly at the point we care about, so plugging in a doesn't work
  • Limits describe the behavior of f(x) as x gets arbitrarily close to a, without requiring f(a) to exist
  • Three behaviors near a single point: approaching one value, jumping between two values, or blowing up without bound

Intuitive Definition of a Limit

  • If the values of f(x) can be made as close as we like to L by taking x sufficiently close to a (but not equal to a), then limx→a f(x) = L
  • The limit describes behavior of a function near a point, not necessarily at that point
  • Strategy: build a table of x-values approaching a from both sides (a ± 0.1, a ± 0.01, a ± 0.001, …) and watch where f(x) settles

Example: Evaluating limx→0 sin(x)/x

  • f(x) = sin(x)/x is undefined at x = 0 (0/0), so it can't be evaluated by direct substitution
  • Table of values from the left (−0.1, −0.01, −0.001) and right (0.1, 0.01, 0.001) both approach 1
  • Conclusion: limx→0 sin(x)/x = 1, even though the function is undefined at x = 0

Example: Evaluating limx→4 (√x − 2)/(x − 4)

  • Direct substitution gives 0/0, an indeterminate form
  • Values approaching x = 4 from both sides settle near 0.25
  • Conclusion: limx→4 (√x − 2)/(x − 4) = 0.25

Theorem 2.1: Two Important Limits

  • limx→a x = a (the limit of the identity function is a)
  • limx→a c = c for any constant c (the limit of a constant function is the constant)

One-Sided Limits

  • Limit from the left: limx→a− f(x) = L, values of x approach a while staying less than a
  • Limit from the right: limx→a+ f(x) = L, values of x approach a while staying greater than a
  • Example: even though g(−1) = 4 (closed circle), limx→−1 g(x) = 3 (open circle) — the function value and the limit can differ

Checkpoint: One-Sided Limits at a Hole

  • Both sides of the graph approach the same open circle, so limx→a− h(x) and limx→a+ h(x) agree
  • A hole (undefined point) does not stop a two-sided limit from existing

Example: A Limit That Does Not Exist

  • limx→0 sin(1/x): as x approaches 0, 1/x grows without bound, so sin(1/x) oscillates infinitely often between −1 and 1
  • The function never settles on a single value near x = 0
  • Conclusion: the limit does not exist (DNE)

Theorem 2.2: Relating One-Sided and Two-Sided Limits

  • limx→a f(x) = L if and only if limx→a− f(x) = L and limx→a+ f(x) = L
  • Example: for f(x) = {x+1 if x<2; x²−4 if x≥2}, limx→2− f(x) = 3 and limx→2+ f(x) = 0
  • Because the one-sided limits disagree (3 ≠ 0), limx→2 f(x) does not exist

Infinite Limits and Vertical Asymptotes

  • For f(x) = 1/x: limx→0− f(x) = −∞ and limx→0+ f(x) = +∞
  • Since the one-sided limits disagree, limx→0 f(x) does not exist
  • The line x = a is a vertical asymptote whenever a one-sided or two-sided limit at a is +∞ or −∞

Theorem 2.3: Infinite Limits from Positive Integers

  • For f(x) = 1/(x−a)n where n is a positive integer:
  • If n is even: limx→a f(x) = +∞
  • If n is odd: limx→a+ f(x) = +∞ and limx→a− f(x) = −∞
  • Example: f(x) = 1/(x+3)4 has a vertical asymptote at x = −3, with the limit equal to +∞ from both sides (n = 4 is even)

Example: Reading Limits, One-Sided Limits, and Values from a Graph

  • Practice distinguishing limx→a− f(x), limx→a+ f(x), limx→a f(x), and f(a) at several points on one graph
  • Open circles mark values excluded from the function; closed circles mark the actual function value
  • A vertical asymptote (here at x = 3) means the one-sided limits there are infinite, so the two-sided limit does not exist

Application: Einstein's Velocity Equation

  • Einstein's equation for the mass of a moving object: m = m0 / √(1 − v²/c²), where m0 is rest mass, v is speed, and c is the speed of light
  • As the speed ratio v/c approaches 1, limv/c→1− m/m0 = +∞
  • An infinite limit here means an object would require infinite mass (and energy) to reach light speed — a real-world use of infinite limits
