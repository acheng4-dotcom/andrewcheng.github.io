The Limit of a Function

Why We Need Limits

  • Some functions are undefined exactly at the point we care about, so plugging in a doesn't work
  • Limits describe the behavior of f(x) as x gets arbitrarily close to a, without requiring f(a) to exist
  • Three behaviors near a single point: approaching one value, jumping between two values, or blowing up without bound

Intuitive Definition of a Limit

  • If the values of f(x) can be made as close as we like to L by taking x sufficiently close to a (but not equal to a), then limx→a f(x) = L
  • The limit describes behavior of a function near a point, not necessarily at that point
  • Strategy: build a table of x-values approaching a from both sides (a ± 0.1, a ± 0.01, a ± 0.001, …) and watch where f(x) settles

Example: Evaluating limx→0 sin(x)/x

  • f(x) = sin(x)/x is undefined at x = 0 (0/0), so it can't be evaluated by direct substitution
  • Table of values from the left (−0.1, −0.01, −0.001) and right (0.1, 0.01, 0.001) both approach 1
  • Conclusion: limx→0 sin(x)/x = 1, even though the function is undefined at x = 0

Example: Evaluating limx→4 (√x − 2)/(x − 4)

  • Direct substitution gives 0/0, an indeterminate form
  • Values approaching x = 4 from both sides settle near 0.25
  • Conclusion: limx→4 (√x − 2)/(x − 4) = 0.25

Theorem 2.1: Two Important Limits

  • limx→a x = a (the limit of the identity function is a)
  • limx→a c = c for any constant c (the limit of a constant function is the constant)

One-Sided Limits

  • Limit from the left: limx→a− f(x) = L, values of x approach a while staying less than a
  • Limit from the right: limx→a+ f(x) = L, values of x approach a while staying greater than a
  • Example: even though g(−1) = 4 (closed circle), limx→−1 g(x) = 3 (open circle) — the function value and the limit can differ

Checkpoint: One-Sided Limits at a Hole

  • Both sides of the graph approach the same open circle, so limx→a− h(x) and limx→a+ h(x) agree
  • A hole (undefined point) does not stop a two-sided limit from existing

Example: A Limit That Does Not Exist

  • limx→0 sin(1/x): as x approaches 0, 1/x grows without bound, so sin(1/x) oscillates infinitely often between −1 and 1
  • The function never settles on a single value near x = 0
  • Conclusion: the limit does not exist (DNE)

Theorem 2.2: Relating One-Sided and Two-Sided Limits

  • limx→a f(x) = L if and only if limx→a− f(x) = L and limx→a+ f(x) = L
  • Example: for f(x) = {x+1 if x<2; x²−4 if x≥2}, limx→2− f(x) = 3 and limx→2+ f(x) = 0
  • Because the one-sided limits disagree (3 ≠ 0), limx→2 f(x) does not exist

Infinite Limits and Vertical Asymptotes

  • For f(x) = 1/x: limx→0− f(x) = −∞ and limx→0+ f(x) = +∞
  • Since the one-sided limits disagree, limx→0 f(x) does not exist
  • The line x = a is a vertical asymptote whenever a one-sided or two-sided limit at a is +∞ or −∞

Theorem 2.3: Infinite Limits from Positive Integers

  • For f(x) = 1/(x−a)n where n is a positive integer:
  • If n is even: limx→a f(x) = +∞
  • If n is odd: limx→a+ f(x) = +∞ and limx→a− f(x) = −∞
  • Example: f(x) = 1/(x+3)4 has a vertical asymptote at x = −3, with the limit equal to +∞ from both sides (n = 4 is even)

Example: Reading Limits, One-Sided Limits, and Values from a Graph

  • Practice distinguishing limx→a− f(x), limx→a+ f(x), limx→a f(x), and f(a) at several points on one graph
  • Open circles mark values excluded from the function; closed circles mark the actual function value
  • A vertical asymptote (here at x = 3) means the one-sided limits there are infinite, so the two-sided limit does not exist

Defining the Derivative

The Difference Quotient

  • Given a point (a, f(a)) on the graph, the difference quotient is Q = [f(x) − f(a)]/(x − a), the slope of the secant line through (a, f(a)) and (x, f(x))
  • Setting x = a + h (h ≠ 0) gives an equivalent form, Q = [f(a+h) − f(a)]/h, where h is the horizontal distance from a to x
  • As x → a (equivalently h → 0), the secant line rotates into the tangent line at (a, f(a))

Definition: Derivative at a Point

  • f'(a) = limx→a [f(x) − f(a)]/(x − a), provided this limit exists
  • Equivalently, f'(a) = limh→0 [f(a+h) − f(a)]/h
  • f'(a) is read "f prime of a" and gives the slope of the tangent line to y = f(x) at x = a
  • If f'(a) exists, f is said to be differentiable at a

Tangent Lines

  • mtan = f'(a): the slope of the tangent line at x = a is the derivative of f at a
  • Point-slope form of the tangent line: y − f(a) = f'(a)(x − a)
  • Example: for f(x) = x² at a = 3, f'(3) = 6, so the tangent line is y = 6x − 9
  • Example: for f(x) = 1/x at a = 2, f'(2) = −1/4, so the tangent line is y = −x/4 + 1

The Derivative as a Function

  • f'(x) = limh→0 [f(x+h) − f(x)]/h, provided this limit exists — the derivative function, obtained by letting the point a vary
  • The domain of f' is the set of all x for which this limit exists; it can be a proper subset of the domain of f
  • Common notations for the derivative: f'(x), dy/dx, y', d/dx[f(x)], Dxf(x) — all denote the same object
  • The value of the derivative notation dy/dx at x = a is written dy/dx|x=a

Example: Finding a Derivative Function

  • For f(x) = x² − 2x: f'(x) = limh→0 [f(x+h) − f(x)]/h = limh→0 [(x+h)² − 2(x+h) − (x² − 2x)]/h
  • Expanding and simplifying the numerator, then dividing by h and letting h → 0, gives f'(x) = 2x − 2
  • Strategy: expand f(x+h), subtract f(x), simplify so h factors out of the numerator, cancel the h in the denominator, then take the limit as h → 0

Derivatives and Rates of Change: Velocity

  • Average velocity over [a, t]: vavg = [s(t) − s(a)]/(t − a), the slope of the secant line on a position-time graph
  • Instantaneous velocity at t = a: v(a) = s'(a) = limt→a [s(t) − s(a)]/(t − a), the slope of the tangent line on a position-time graph
  • The derivative of a position function is a velocity — the general pattern behind every "instantaneous rate of change" interpretation of f'(a)

Related Rates

The Idea Behind Related Rates

  • When two or more related quantities are all changing with respect to time, an equation connecting them can be differentiated with respect to time to connect their rates of change
  • Because every quantity in the equation is implicitly a function of t, the chain rule applies to each term: d/dt[r³] = 3r² · dr/dt, not just 3r²
  • Do not substitute the known numerical values until after differentiating — substituting too soon freezes a changing quantity as if it were constant

Problem-Solving Strategy for Related Rates

  • 1. Assign variables to all quantities that are functions of time; draw a diagram if the problem is geometric
  • 2. Write down the given rate(s) and identify the rate that must be found
  • 3. Find an equation relating the variables in step 1
  • 4. Differentiate both sides of the equation with respect to time t, using the chain rule as needed
  • 5. Substitute the known values and solve the resulting equation for the desired rate

Example: Inflating a Balloon

  • Volume and radius of a sphere are related by V = (4/3)πr³
  • Differentiating with respect to t: dV/dt = 4πr² · dr/dt
  • Given dV/dt = 2 cm³/sec and r = 3 cm, solving gives dr/dt = 1/(18π) cm/sec

Example: An Airplane Passing Overhead

  • The Pythagorean theorem relates the variables: x² + 4000² = s²
  • Differentiating with respect to t: 2x · dx/dt = 2s · ds/dt
  • Given x = 3000 ft, dx/dt = 600 ft/sec (so s = 5000 ft by the Pythagorean theorem), solving gives ds/dt = 360 ft/sec

Example: Rocket Launch Tracked by a Camera

  • The camera angle and rocket height are related by tanθ = h/5000
  • Differentiating with respect to t: sec²θ · dθ/dt = (1/5000) · dh/dt
  • Given h = 1000 ft and dh/dt = 600 ft/sec, solving gives dθ/dt = 3/26 rad/sec

Example: Water Draining from a Funnel

  • Similar triangles relate the water's radius and height: r = h/2, which reduces the cone volume formula to V = (π/12)h³
  • Differentiating with respect to t: dV/dt = (π/4)h² · dh/dt
  • Given dV/dt = −0.03 ft³/sec and h = 1/2 ft, solving gives dh/dt ≈ −0.153 ft/sec

Linear Approximations and Differentials

Linear Approximation

  • The tangent line to y = f(x) at x = a, y = f(a) + f'(a)(x − a), closely approximates f(x) for x near a
  • Linear approximation (tangent line approximation): L(x) = f(a) + f'(a)(x − a)
  • For x sufficiently close to a, f(x) ≈ L(x); the approximation degrades as x moves farther from a

Example: Approximating √9.1 and sin(62°)

  • For f(x) = √x at a = 9: L(x) = 3 + (x − 9)/6, so √9.1 ≈ L(9.1) = 3.0167, very close to the actual value 3.0166
  • For f(x) = sin x at a = π/3 (60°): the tangent line approximates sin(62°) ≈ 0.88348
  • Linear approximation also justifies the small-angle estimate (1+x)n ≈ 1 + nx near x = 0, e.g. 1.01³ ≈ 1.03

Differentials

  • Given y = f(x) differentiable, the differential dx is an independent variable that can take any real value
  • The differential dy is defined as dy = f'(x) dx, giving Leibniz notation dy/dx a literal meaning as a ratio of differentials
  • Δy = f(x + dx) − f(x) is the actual change in y; dy is the change along the tangent line — for small dx, Δy ≈ dy

Calculating Differentials and Approximating Change

  • For y = x² + 2x: dy = (2x + 2) dx
  • For y = cos x: dy = −sin x dx
  • Comparing exact vs. approximate change for y = x² + 2x from x = 2 to x = 2.1 (dx = 0.1): Δy = 0.81 while dy = 0.8, showing dy closely approximates Δy

Error Propagation

  • If dx = Δx represents the measurement error of a quantity, the propagated error in a computed value is approximately Δy ≈ dy = f'(a) dx
  • Relative error is the ratio Δq/q of the error to the measured quantity; percentage error expresses relative error as a percentage
  • Example: measuring a cube's side as 5 cm ± 0.1 cm gives a propagated volume error of about ±7.5 cm³
  • Example: a 6% error in measuring Earth's radius as 4000 ± 80 mi propagates to roughly a 6% error in the computed volume (since dV/V = 3 dr/r)
